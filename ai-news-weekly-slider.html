Anthropic IPO 資本市場
AnthropicがSECにIPOを機密申請
評価額9,650億ドル（約140兆円）でOpenAIを超えた
Claudeを開発するAnthropicが、米SECにForm S-1の草案を非公開提出。シリーズHで650億ドルを調達し評価額は約9,650億ドルに達し、初めてOpenAIを時価総額で上回りました。上場時に1兆ドルを達成すれば、サウジアラムコ・SpaceXに次ぐ史上3位規模の上場となる見通し。日立・富士通・ソフトバンクGなどClaude採用の国内大手にも影響が注目されています。
📅 2026年6月1日 ／ SEC提出資料ほか

02
Microsoft Windows AIエージェント
Microsoft Build 2026開幕
「Windowsはもはや人間だけのものではない」と宣言
Satya Nadella CEOがサンフランシスコで開催されたBuild 2026でWindowsをAIエージェント専用OSへ刷新すると宣言。Windows Agent Framework（オープンソース）・Azure Agent Mesh・WSL 3・Copilot Workspace一般提供など大規模なエージェントスタックを発表。さらに自社製コーディングAI「Project Polaris」（MoEアーキテクチャ）を発表し、GitHub Copilotのデフォルトモデルを2026年8月からPolarisへ移行する計画も明らかにしました。
📅 2026年6月1〜2日 ／ Microsoft Build

Apple Siri WWDC 2026
iOS 27のSiriがGoogle Gemini基盤で全面刷新
Claude・ChatGPTも選択可能に
Apple WWDC 2026（6月8〜12日）にてiOS 27が発表。SiriをGoogle Geminiベースで全面的に作り直し、Private Cloud Computeで処理する新アーキテクチャを採用。ExtensionsフレームワークによりClaude・ChatGPT・Geminiを用途に応じて選択できる仕組みを導入。Googleへの年間支払いは約10億ドルと報じられており、AI主導のスマートフォン体験が大きく変わります。
📅 2026年6月8〜12日 ／ Apple WWDC

NVIDIA ローカルAI ハードウェア
NVIDIA「RTX Spark」発表
AIエージェントがPCの中で動く時代へ
Jensen Huang CEOがComputex 2026でローカルAI推論に特化したスーパーチップ「RTX Spark」を発表。秋よりDell・HP・ASUS・Lenovo・MSIの搭載PCが登場予定。クラウドに依存せず手元のPCでAIエージェントを動かせる環境が整い、機密データを扱う医療・金融・法務分野での活用が加速する見通し。次世代「Vera Rubin（2027）」・「Rosa Feynman（2029）」のロードマップも公表しました。

SpaceX Cursor コーディングAI
SpaceXがAIコーディングツール「Cursor」の
運営会社を600億ドルで買収へ
SpaceXが、人気AIコーディングツール「Cursor」を開発するAnysphere社を600億ドルで買収する方向で交渉中と報じられました。上場直後の大型AI投資として業界に衝撃を与えています。開発者の生産性向上ツールへの争奪戦が激化するなか、宇宙企業が本格的なAIソフトウェア企業へと変貌する象徴的な動きとして注目されています。（Ledge.ai 2026年6月報道）
